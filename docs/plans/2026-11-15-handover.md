## 六、纪律红线（接手后必守，均出自 AGENTS.md 与工程惯例）

1. **前端视觉算子任何变更 → 必须真数据全流程验证**（2026-09-04 合成测试通过但真实数据翻车当日回滚的教训；PJC 对盆地敏感）。
2. **验收双轨制**：流程类改动要求产物 SHA256 逐字节一致；算术类改动走数值门＋真数据 PASS。
3. 改主库 JSON 必须 UTF-8 写入（历史上 ANSI 编码事故曾致参数静默失效）。
4. 合入验证要看"并行乱序证据"而非只看耗时（曾有工具假成功事故）。
5. `factory_calib` 与 `modules/09_operatorlib` 是逐字拷贝同步边界——单侧改动记债务，两侧同改。
6. 数据集 config 里的显式零值键（如 `postErodeSize=0`）**不可删**（编译默认值非零，删了会灭线）。
