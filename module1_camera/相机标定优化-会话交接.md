## 一、三批合入明细（改动位置与证据）

### 批次一：内参 LU 解方程器（2026-10-13）

| 项 | 内容 |
|---|---|
| 病根 | OpenCV `calibrateCameraRO` 每轮 LM 迭代对 ~780×780 矩阵做稠密 SVD（OpenCV 自带实现极慢）＋默认终止条件恒跑满 30 轮；内部多线程仅 1.2 倍贡献 |
| 改动 | 3 个配置文件 `intrinsic_flags: 0 → 131072`（=CALIB_USE_LU）：主库 `camera_calib_params.json`、`test_data/camera/config.json:8`、`tests/e2e/data_out/config.json:8` |
| 证据 | E1 实验（3+3 ABBA 中位）：578s→6.3s；K 差 7e-14、rms 差 1e-15、下游极线差 1e-12（门限富余 ≥6 个数量级） |
| 注意 | `intrinsic_flags` 是**整值替换**非按位或；数据集 config 含此键会静默覆盖主库（present-key 逐叶覆盖） |

### 批次二：CLI 角点并行（2026-10-14）

| 项 | 内容 |
|---|---|
| 改动 | `camera_calib_cli.cpp` 角点循环 → 12 worker 帧级并行（原子递增动态取帧＋`recs[i]` 槽位写）＋提取期间 `cv::setNumThreads(1)`（存还原）＋`calib_io.h/.cpp` 新增 `cornerWorkers` 参数与 `corner.workers` 解析＋主库 json `corner:{workers:12}` |
| 证据 | camera261006-1688 复跑 115.8s→79.9s（角点段 78→29s）；输出与批次一金标 **SHA256 逐字节一致**；日志告警乱序＝并行生效铁证 |
| 关键认知 | OpenCV 有**嵌套并行闸**（parallel.cpp flagNestedParallelFor）：任一线程占用并行区期间其他线程 parallel_for 串行内联——这是帧级并行天真做只有 2.7 倍的真因；纯调度天花板 ~25s |

## 二、实验场 opt_bench（tests/opt_bench/，18 个测试）

**双轨验收制**：流程类改动（不改数值）要求逐字节一致；算子类改动（改数值）要求数值门内不劣化（K≤1e-8/畸变≤1e-7/rms≤1e-6/下游≤1e-3）。
**计时规范**：3+3 次 ABBA 换序取中位（本机噪声 ±20%）。共享件强制 header-only（tests/ 下非 test_ 前缀 .cpp 会被 CMake 路由丢弃）。

| 测试 | 结论 |
|---|---|
| test_calib_baseline | 基准：与历史 camera_calib.json 对拍自检（rms/帧数全吻合） |
| test_opt_intrinsic_lu (E1) | **92 倍，已转化批次一** |
| test_opt_extrinsic_lu (E6) | **67 倍，已转化批次三** |
| test_opt_parallel_corner (S1) | 2.70 倍逐点一致，已转化批次二 |
| test_opt_corner_10s | 四臂：串行 65s/8w 默认 27s/12w+关内部线程 25s/**合成方案 7.8s**——7.8s 方案未合入（见 §三） |
| test_opt_frame_reject (A1) | 自动剔 6 帧＝人工标注 6/6 全中，全指标改善——**待立项** |
| test_diag_intrinsic_threads | OpenCV 内部弱并行（1.2 倍），线程数不改结果 |
| test_opt_sb_two_stage (S2) | 已否决：精度无损但慢 26% |
| test_opt_intrinsic_parallel (E2) | 已验证不采纳：LU 后仅省 3 秒 |

**测试分档**：交付回归＝`ctest -E "^test_opt_|^test_diag_intrinsic_threads"`（10 项约 2 分钟）；实验全量＝不过滤（18 项约 50 分钟，慢因＝各实验须重演慢基线臂做对照）。

## 四、事故教训（下会话避坑）

1. **PowerShell `Set-Content` 默认 ANSI 编码会写坏 UTF-8 中文 JSON** → 解析失败后 CLI **静默回退编译内置默认**（慢模式），曾产出 803s 废数据。改主库 json 须从源码树拷贝或 `[System.IO.File]::WriteAllText`+UTF8
2. **工具假成功＋MSBuild 陈旧 obj**：曾有编辑报告成功但源文件未变、以及源文件变了但 obj 未重编（链接照过、行为照旧）——**改动后必须 grep 源文件确认内容、盯编译行确认真编了，必要时删 obj/lib 强制**；验证并行生效**必须查日志乱序证据**（失败帧告警顺序非递增），不能只看耗时
3. 本机计时噪声 ±20%——小于 1.5 倍的差异一律用 3+3 ABBA 中位判读

## 六、方法论文档（可复用到其他优化）

多代理回合制：3 设计代理（调度/算法/IO 三视角）→ 3 审核代理（数值/工程/实验设计）→ 2 对抗审核代理 → 实现 → 红修到绿。本轮实证其价值：审核**驳回过 1 个逻辑洞方案**（两阶段初值不减轮数）、**预言过 B 类扩集**（角点快检测翻车主因）、揭过 setNumThreads(0)≠恢复默认的语义坑。
